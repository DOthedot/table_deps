table-deps · Welcome guide mockup

A centered card on first visit. Five short scenes, each a looping animation built from CSS (no video files), showing what to do and where. Dismissible, shown once, and reopened from ? in the header. The scenes are stand-ins; the real app is unchanged.

How it behaves

Option chosen: animated illustrations · centered card.

When it shows

  • On the first visit to either page. "Seen" is remembered in this browser (localStorage).
  • Never again after ✕, Skip, Esc, a click on the backdrop, or the last step.
  • ? Reopen any time from the ? button in the header, or the ? key.
  • On a shared deep link (?t= or ?sel=) it stays closed and the ? button pulses instead, so a shared link opens straight to what was shared.

The five scenes

  1. What table-deps is
  2. Query view: paste SQL → Analyze
  3. Project view: open a folder → DAG
  4. Click a node → inspector → open its query
  5. Shortcuts: 1 2 ⌘K Esc

Controls

  • ← → or the dots change step; Esc closes.
  • Last step: Explore example project (opens Kimball) or Paste my own SQL (closes the guide and focuses the SQL box).
  • Reduced-motion users see a still final frame of each scene.

Cost

  • One new tour.js + tour.css, ~10 KB, no images or video. No changes to the graphs.

Open question
