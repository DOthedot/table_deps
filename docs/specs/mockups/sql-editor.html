SQL editor

One button opens it; it edits the same SQL as the sidebar box. Nothing is saved anywhere else.
  1. 1⤢ Expand sits in the SQL box corner. It's always visible and lights up on hover or focus. Shortcut ⌘⇧E / Ctrl⇧E.
  2. 2Floating window: drag it by the title bar and resize it from the corner, so the graph stays visible behind it. Focus mode (⤢ in the title bar) fills the screen for long queries.
  3. 3Highlighting covers keywords, strings, numbers and comments. Referenced tables are coloured by schema, the same colours as the graph.
  4. 4Format ⇧⌥F uppercases keywords and puts each clause and select column on its own line. One ⌘Z undoes it.
  5. 5Lint shows wavy underlines, gutter dots and a Problems list. Click a problem to jump to its line; some have a one-click Fix.
  6. 6Analyze ⌘↵ updates the graph behind the editor. The Live switch re-analyzes as you type (debounced).

Lint rules (v1)

🔴 unbalanced-parensA ( without a matching )
🔴 trailing-comma, right before FROM
🔴 join-without-onJOIN without ON/USING (except CROSS)
🟠 select-starSELECT * hides column lineage
🟠 implicit-joinFROM a, b: use an explicit JOIN
🔵 keyword-caseMixed keyword case; Fix runs Format

From a project file

  • Opens read-only with a banner. Lint still runs; Format is disabled until you click Edit as scratch.

Try it

→ Click ⤢ on the SQL box → Click a problem, or its Fix → Press Format, then ⌘Z → Type JOIN dim.store s and watch the lint → Drag the title bar; resize the corner → Analyze, and the graph behind updates
